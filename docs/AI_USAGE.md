## Tool Used

**Claude Code**

## How It Was Used

The agent was used as a development assistant throughout the project. It was used for:

- Understanding the assignment requirements and translating them into an implementation plan.
- Discussing and refining frontend, backend, API, database, and audience evaluation design decisions.
- Building and iterating on parts of the implementation.
- Debugging TypeScript, build, configuration, and testing issues.
- Thinking through edge cases and reviewing implementation choices.
- Designing and refining automated tests for the evaluator and API.
- Reviewing the implementation against the assignment requirements.
- Assisting with project documentation and README content.

AI assistance was primarily used to speed up development and explore possible solutions. The final implementation and repository changes were reviewed by me.
